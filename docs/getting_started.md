# Getting started

1. Clone the repository.
2. Choose the system-specific pipeline under `pipelines/`.
3. Read the preparation README and inspect the user settings in `md_prep.sh`.
4. Provide the required structure, topology/parameter files, and `.mdp` files.
5. Run the preparation workflow.
6. Review the resulting simulation files before production MD.
7. Run the analysis workflow after the trajectory is available.

Do not run a production simulation without reviewing the system-specific settings and validating the generated topology and index groups.
